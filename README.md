# SQL-Final-Project.
SQL | Анализ клиентских транзакций

Финальный проект Academica — аналитика данных

О проекте

Анализ покупательской активности клиентов за период с 1 июня 2015 года по 31 мая 2016 года с использованием MySQL.

Данные: 2 429 клиентов и 419 122 товарные строки транзакций в исходном наборе.

Инструменты: MySQL, MySQL Workbench, SQL, CTE, оконные функции, JOIN, агрегирование.

Выполненные задачи

1. Анализ постоянных клиентов

Выявлено 82 клиента, совершавших покупки во всех 12 месяцах.

Рассчитаны количество уникальных чеков, средний чек и среднемесячная сумма покупок.

2. Помесячная аналитика

Средний чек и количество операций.

Среднее количество активных клиентов — 965,17 в месяц.

Доли операций и суммы покупок по месяцам.

Распределение M/F/NA и доли затрат.

3. Возрастная сегментация

Возрастные группы с шагом 10 лет.

Отдельная категория «Не указан».

Количество операций, суммы покупок, средние показатели и процентные доли за год и по кварталам.

Основные выводы

Обнаружен клиент с аномально высокой активностью — 6 677 уникальных чеков за анализируемый период.

Наибольшая доля операций приходится на возрастную группу 60–69 лет — 26,01%.

Выявлены необычно низкие значения возраста, требующие проверки исходных данных.

Все операции датированы первым числом месяца, что ограничивает возможность анализа покупок по дням.
